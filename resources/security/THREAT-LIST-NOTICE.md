`threat-domains.txt` is the unmodified domain-format, medium Threat Intelligence
Feed from https://github.com/hagezi/dns-blocklists. Its source URL and generation
date are preserved in the file header. It is distributed as separate data under
GPL-3.0; see THREAT-LIST-LICENSE.txt. Voyager application code has its own license.

The list is fetched from the same public upstream URL for periodic refreshes.
Only domain strings are interpreted; executable filters and scripts are rejected.
List inclusion can be mistaken and does not establish that every URL on a domain
is malicious. False positives can be reported through the upstream Issues URL
in the list header. Absence from the list does not establish that a site is safe.
